# What's New in v1.9.0

Date: 2026-01-16

## Changes

### [PR #167](https://github.com/humlab-sead/sead_shape_shifter/pull/167) feat: enhance YAML editor with entity and project validation \(\#166\)

When editing project or entity YAML in the editor, users now get autocompletion for entity names,
data sources, and enum values, plus immediate in-editor errors and warnings for structural problems
and references to unknown entities.

### [PR #168](https://github.com/humlab-sead/sead_shape_shifter/pull/168) Add YAML schema validation and autocompletion in Monaco editor

When editing project or entity YAML, the editor now highlights structural errors and invalid
references (for example an unknown entity in depends_on or foreign_keys) and offers context-aware
autocompletion for entity names, data sources, join types, and other values, making typos in YAML
configuration easier to catch while typing.

## Upgrade Notes

### [PR #167](https://github.com/humlab-sead/sead_shape_shifter/pull/167)

Frontend dependencies changed (monaco-yaml and yaml were added); run pnpm install in frontend/
before building. Existing project YAML files may now surface new validation markers (for example,
entity type values outside the schema enums), so review any new editor warnings after upgrading;
input/arbodat-test.yml was updated accordingly in this PR.
