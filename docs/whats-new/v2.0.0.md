# What's New in v2.0.0

Date: 2026-04-01

## Highlights

- Configure merged entities from branches, with a graph and preview to inspect the result.
- Edit target model YAML in the application and check project data against target model rules.
- Configure bridge entities for many-to-many relationships and defer circular foreign key links.

## New Features

### Branches and merged entities

Create a merged entity from multiple branches, edit its configuration, and inspect the merged entity graph and preview. Validation now accounts for branch configuration.

### Target model editing and validation

Edit target model YAML in the application. Shape Shifter can also check a project's entities and data against target model requirements, including relationship and source type rules.

### More relationship and append options

Bridge entities can represent many-to-many relationships. The append editor now supports choosing a source and how source rows align with target rows.

## Improvements

- Append alignment and validation now account for entity identity and keep existing append settings when editing a project.
- Deferred foreign key links can be retried after dependent entities are processed.

## Upgrade Notes

No breaking changes are listed for this release. Branch, bridge entity, and target model validation features are opt-in.
