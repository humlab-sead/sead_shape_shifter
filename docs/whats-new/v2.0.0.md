# What's New in v2.0.0

Date: 2026-04-01

## Changes

### [PR #390](https://github.com/humlab-sead/sead_shape_shifter/pull/390) Add target\-model conformance validation and SEAD v2 spec

Projects can now reference a target model specification (for example the bundled SEAD Clearinghouse
spec) in their metadata, and a new "Check Conformance" action in the Validate tab reports whether
the project's entities meet that spec's required entities, columns, foreign keys, and public_id
naming rules, shown in a dedicated Conformance panel. A starter project YAML can also be generated
from a target model spec to scaffold new projects.

### [PR #392](https://github.com/humlab-sead/sead_shape_shifter/pull/392) feat\(backend\): implement boundary\-based project persistence

Editing a project's options, metadata, or a single entity now preserves the rest of the project YAML
file, including any comments and formatting users have added. Saves no longer rewrite the entire
project document, reducing the chance of overwriting concurrent changes to other sections.

### [PR #394](https://github.com/humlab-sead/sead_shape_shifter/pull/394) feat: entity\-level optimistic locking with ETag support

When you save an entity that another user has already modified, Shape Shifter now detects the clash
and reports a conflict ("reload before saving") instead of silently overwriting the other edit,
helping you keep concurrent changes intact.

### [PR #411](https://github.com/humlab-sead/sead_shape_shifter/pull/411) Add first\-class merged parent entities with branch support

You can now build a shared parent entity from multiple source entities using type: merged with an
explicit branches: list: Shape Shifter assembles the rows, adds a branch discriminator column and
sparse lineage foreign keys back to each branch source, and the editor provides a Branches tab,
merged/branch-source preview, branch-grouped validation, and branch-aware dependency-graph edges.
You can also paste tabular data from a spreadsheet directly into a fixed-values grid.

### [PR #412](https://github.com/humlab-sead/sead_shape_shifter/pull/412) Add target\-model conformance, merged entities, and editor UX features

Users can now check a project against a target model specification (such as the bundled SEAD v2
spec) from the VALIDATION tab and view or edit the target model in the YAML editor, and can create
"merge" entities that combine data from multiple sources. The fixed values grid now accepts pasted
clipboard data, and an in-app What's New changelog surfaces recent feature updates.
