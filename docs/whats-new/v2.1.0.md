# What's New in v2.1.0

Date: 2026-09-09

## Highlights

- Define derived entities with SQL queries using the new DuckDB-backed internal entity type.
- Check project data against target model rules, with controls for rule severity and whether a rule runs.
- Add built-in value conversion and text functions to `extra_columns` expressions.
- Generate a SIMS entity register from target model identity and relationship metadata.

## New Features

### SQL-derived entities

Use the `duckdb` entity type to query already processed entities and create derived results without configuring an external database connection.

### Target model checks and documentation

Run target model-aware conformance checks, adjust rule severity, and disable rules where needed. The target model schema reference can be generated and downloaded. Target model documentation can also include a SIMS entity register describing identity tracking, aggregation, and reconciliation details.

### Data preparation and change requests

`extra_columns` expressions now include functions for converting values to integers, decimals, strings, and dates, as well as replacing text and extracting text with regular expressions. The SEAD change request workflow can classify submission outcomes and handle accepted updates to existing rows.

## Improvements

- Fixed entity editors support additional column types and preserve typed values more consistently.
- Reconciliation links can be managed and exported for use in mapping files.
- Validation reports more target model and project configuration issues, including transitive relationship problems.

## Upgrade Notes

No breaking changes are listed for this release. Existing projects can continue using their current entity types and expressions; the new DuckDB entity type and expression functions are available when needed.
