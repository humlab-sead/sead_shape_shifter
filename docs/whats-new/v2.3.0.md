# What's New in v2.3.0

Date: 2026-10-05

## Highlights

- Generate public identifiers from database sequences and resolve SIMS work in ordered batches.
- Export target model type tables to an Excel workbook.
- Add an example environment configuration file and stricter checks for environment variable expansion.
- Improve protection for project files and application paths.

## New Features

### Target model exports and identifiers

Export target model type tables to Excel. Target models can also use database sequences to generate public identifiers.

### SIMS identity handling

SIMS ingester workflows can resolve work in one ordered batch, bind approved aggregate IDs, and reserve sequence IDs. A capability check runs before processing so unsupported SIMS operations stop before changes are made.

## Improvements

- The new `.env.example` file shows the supported environment configuration variables.
- Proposed SIMS bindings are no longer confirmed automatically; review them before approving a binding set.
- The application includes an introduction to project workflows and data preparation.

## Fixes

- Project create, copy, and delete operations now keep file paths within the configured project location.
- File-based entity types are rejected if Shape Shifter cannot check that their paths remain in an allowed location.
- Dependency errors now identify the dependency that could not be materialized.

## Upgrade Notes

No breaking changes are listed for this release. Review the environment variable allowlist if a project uses `${ENV_VAR}` expansion, and update deployment environment files from the provided example as needed.
