# What's New in v1.5.0

Date: 2026-01-14

## Changes

### [PR #150](https://github.com/humlab-sead/sead_shape_shifter/pull/150) feat: add configurable UID/GID to Docker setup and Makefile targets

Docker deployments now run as a non-root user whose UID/GID can be set at build time (defaults to
1000:1000), which fixes permission problems when writing to mounted data directories. Setup is
simpler: one make setup command creates the required directories and configuration files, replacing
the old shell scripts.

### [PR #151](https://github.com/humlab-sead/sead_shape_shifter/pull/151) Add configurable UID/GID to Docker setup and consolidate on Makefile

Docker deployment is now driven entirely by simple make commands (make setup, make docker-build,
make docker-up), and the container can run with your own user ID so mounted data directories no
longer hit permission problems.

## Upgrade Notes

### [PR #150](https://github.com/humlab-sead/sead_shape_shifter/pull/150)

- The helper scripts docker/build.sh, docker/setup.sh, docker/test.sh, and docker/test-build.sh are
removed. Use the Makefile equivalents instead: make setup (was setup.sh), make docker-build (was
build.sh), and make docker-validate / make docker-test (were test.sh / test-build.sh).
 - docker/nginx.conf.example has been deleted; deployments relying on it must maintain their own
reverse-proxy configuration.
 - The Makefile defaults USER_UID/USER_GID from the sead system user (id sead -u/-g). If that user
does not exist on your host, override them explicitly (e.g. make docker-build USER_UID=$(id -u)
USER_GID=$(id -g)), matching the value used for make setup-volumes and in docker-compose.yml.
 - Existing docker/data/ directories may need ownership updated to the configured UID/GID (make
setup-volumes does this via sudo chown).
 - The container health check now probes /api/v1/health instead of /; external monitoring using the
old root-URL probe should be updated.

### [PR #151](https://github.com/humlab-sead/sead_shape_shifter/pull/151)

- The removed scripts (docker/build.sh, docker/setup.sh, docker/test.sh, docker/test-build.sh) are
replaced by Makefile targets: use make setup, make docker-build, and make docker-test instead.
docker/nginx.conf.example was also deleted.
 - If your host UID/GID is not 1000:1000, rebuild and run with matching values, e.g. USER_UID=$(id
-u) USER_GID=$(id -g) make docker-build && USER_UID=$(id -u) USER_GID=$(id -g) make docker-up, and
re-run make setup-volumes to fix data directory ownership.
 - The container now runs as the non-root user and reads .pgpass from /app/.pgpass (previously
/root/.pgpass); custom deployments that relied on the old mount location need updating.
 - Container health is now reported via /api/v1/health; external monitors or scripts probing /
should be repointed.
