## Summary

This is the first alpha release of Shape Shifter, delivered as a dev → main merge (510 files
changed). It packages the three components of the mono-repo — the core Python library (src/), the
FastAPI backend, and the Vue frontend — plus the SEAD ingester (ingesters/sead/) into a deployable
alpha.

Key changes visible in the diff:

 - Core library: new replace transform (src/transforms/replace.py), filter metadata support, a new
src/reconciliation/ domain module (model + source strategy), pure-domain data validators
(src/validators/), expanded entity specifications, path utilities, and Excel/SQL loader
improvements.
 - Backend: new endpoints for columns, directives, and filters; the monolithic reconciliation
service is replaced by a backend/app/services/reconciliation/ package with a mapper; data validation
moves to a DataValidationOrchestrator calling pure domain validators; the project service is split
into a services/project/ package; new centralized exceptions, error tips, and request-correlation
middleware; a file-path resolver and column-introspection service. The experimental test-run feature
(endpoint, service, and frontend UI) is removed.
 - Frontend: new components including a log viewer overlay, create-entity-from-table dialog,
replacements editor, copy-project dialog, and preview error display; updated user guide.
 - Housekeeping: documentation restructured (current guides kept, historical notes moved to
docs/archive/, new ingester and testing guides added), sample project configs and generated output/
CSVs removed from the repository, and AI-agent tooling added (AGENTS.md, prompts/, updated copilot
instructions).

## User-facing release note

Shape Shifter's first alpha is now available: users can create transformation projects, define and
preview entities from Excel, CSV, or database sources, apply filters, replacements and links,
reconcile lookup values, and materialize normalized SEAD tables through the web interface.

## Upgrade notes

This is the first release on main, so no migration is required for new installs. For anyone
following the dev branch: the experimental test-run feature (API endpoints, service, and UI) has
been removed, and sample project files and generated output/ CSVs are no longer tracked in the
repository — keep any needed project YAML/Excel files outside the repo working tree.
