## User-facing release note

Validation results and entity previews now report data-quality findings from normalization, such as
join row-count changes, and the validate_project.py CLI can print results as a Markdown report with
--output-format report. Projects referencing a shared target model can now view its YAML read-only
in the project editor and download its documentation, while editing remains blocked.

## Upgrade notes

 - Projects or scripts that reference the old ArboDat helper entity names (_pcodes,
_project_contact) or the per-domain property-type entities must use the renamed helpers
(pcodes_helper, project_contact_helper) and the consolidated property_type entity; the backend
table_name_ignores configuration was updated accordingly.
 - The shared SEAD standard target model now marks the submission entity as required, which can add
conformance findings for projects validated against it.
 - When GLOBAL_TARGET_MODEL_DIR is unset, the validate_project.py CLI now defaults to the repository
resources/target_models directory; set the variable (environment or env file) to keep a different
shared model directory.
