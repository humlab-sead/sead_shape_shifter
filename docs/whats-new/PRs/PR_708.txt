Adds a promote-dev-to-staging Makefile target that wraps scripts/promote_dev_to_staging.sh prepare,
so creating a draft dev-to-staging promotion pull request and preparing its description from branch
history can be done with make promote-dev-to-staging. The script itself is unchanged;
scripts/README.md is updated to document the new target alongside the direct script invocation.
