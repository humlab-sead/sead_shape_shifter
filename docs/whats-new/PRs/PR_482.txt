## User-facing release note

Shape Shifter now includes a SEAD change-request ingester that turns source submissions into
reviewed change-request packages, and per-entity reconciliation policies help match incoming rows
against existing SEAD data. The project editor also gains an improved fixed-values grid and a DuckDB
data loader.

## Upgrade notes

 - Target model files moved from target_models/ to resources/target_models/; update any paths that
reference the old location.
 - Relative data paths (projects/, logs/, shared/) are now resolved against APPLICATION_ROOT; set
SHAPE_SHIFTER_APPLICATION_ROOT or SHAPE_SHIFTER_ENV_FILE if you relied on the previous
working-directory-based resolution.
 - A new optional SHAPE_SHIFTER_SIMS_SERVICE_URL setting points to the authority service for
/identity endpoints; set it if you use the SIMS/change-request features.
 - Copilot prompt files moved from prompts/ to .github/prompts/; update any editor shortcuts or
links to the old paths.
