## Summary

Promotes dev into main, releasing the work accumulated since v2.1.0. The diff (1,500 changed files
against main) is dominated by:

 - Centralized authorization — a new backend/app/authorization/ package (policy, repository, grants,
deployment roles, audit events, FastAPI dependencies), trusted-proxy identity handling via an
AuthenticationAdapter, and route-level enforcement that conceals unauthorized resources as 404
responses. Existing backend API tests were converted to async tests using a new authorized_client
fixture, and a new backend/tests/authorization/ suite covers the adapter, dependencies, route
authentication, and cross-resource access.
 - SQL safety — a shared read-only statement policy in src/sql_policy.py now used by the core
loaders and the backend.
 - Deployment and verification — runtime tooling moved from docker/ to a Podman-based container/
tree (bootstrap, nginx auth configuration, manifest import/export/backup/rollback, and
container/scripts/verify/ checks), plus PostgreSQL read-only role scripts under scripts/postgres/.
 - Documentation — authorization policy and route inventory docs, and archived cutover phase plans
and handoffs under docs/proposals/.

The PR description states origin/main was a clean ancestor of origin/dev and the merge carries 269
commits; the merge completed as commit 43c92b4.
