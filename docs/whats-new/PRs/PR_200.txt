title: Handle missing entities, add graph edit menu and materialized styling
description:
## Summary

This PR improves the dependency graph feature and entity editor robustness across backend and
frontend:

 - Backend (dependency_service.py): DependencyNode now carries a materialized flag, derived from
each entity's materialized.enabled config, so the dependency graph reports which entities are
materialized.
 - Frontend graph: DependencyNode type gains an optional materialized property; graphAdapter.ts maps
it to a materialized Cytoscape class, and cytoscapeStyles.ts adds a distinct style for such nodes
(double green border, slight transparency). ProjectDetailView.vue adds a small legend explaining the
materialized indicator.
 - Context menu: GraphNodeContextMenu.vue adds an "Edit Entity" item that emits a new edit event;
ProjectDetailView.vue handles it by opening the entity editor overlay on the form tab. The menu's
position: 'fixed' style is now typed with as const for type safety.
 - Editor overlay fallback: When the overlay entity is not found in the store, a default object ({
name, entity_data: {} }) is passed instead of null, avoiding a missing-entity error.
 - Makefile (docker/Makefile): GIT_REF default changed from main to dev, docker-build-github now
uses $(GIT_REF) instead of a hardcoded main, and the docker-build-tag target was removed.

## User-facing release note

Entities in the dependency graph can now be edited directly from the node's right-click menu, and
materialized entities are visually marked with a green double border (with a legend in the graph
panel). The entity editor also opens reliably even when the selected entity is not yet loaded in the
store.

## Upgrade notes

Deployers using the Docker Makefile targets should note: GIT_REF now defaults to dev instead of main
(override it explicitly to build from another ref), and the docker-build-tag target has been
removed — use build.sh --git-ref <tag> directly or set GIT_REF when building from a specific tag or
branch. No end-user action is required.
