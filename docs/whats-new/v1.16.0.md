# What's New in v1.16.0

Date: 2026-01-29

## Changes

### [PR #186](https://github.com/humlab-sead/sead_shape_shifter/pull/186) Fix entity editor system\_id/public\_id handling

When editing fixed entities, the values grid now shows the system ID as an auto-numbered, read-only
column and highlights the public ID column, making these identifier fields easier to work with.

### [PR #187](https://github.com/humlab-sead/sead_shape_shifter/pull/187) Add rsync\-to\-sead\-tools script and improve entity editor ID columns

When editing fixed entities, the values grid now automatically numbers the read-only system_id
column and highlights the public_id column, making identifier columns easier to recognize and less
error-prone to edit.
