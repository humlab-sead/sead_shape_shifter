## Pending Release

- [PR #615](https://github.com/humlab-sead/sead_shape_shifter/pull/615) chore: promote dev into staging (merged 2026-10-28).
- [PR #621](https://github.com/humlab-sead/sead_shape_shifter/pull/621) Add target\-model guided entity creation, verify auth route metadata (merged 2026-10-28).
  - User-facing release note:
    When adding an entity to a project with an associated target model, users can now pick a missing
    target-model entity in the "Start from target model" picker: the entity name and public ID are
    prefilled, the target's required columns and links (including conditional links) are shown as
    reference information, and the entity is saved only through the normal create action. Manual entity
    creation remains fully usable when no target model is configured or the options request fails.
- [PR #625](https://github.com/humlab-sead/sead_shape_shifter/pull/625) chore: promote dev into staging (merged 2026-10-28).
  - Promotes: #621.
- [PR #626](https://github.com/humlab-sead/sead_shape_shifter/pull/626) Enhance cached value reference UX in entity forms (merged 2026-10-29).
  - User-facing release note:
    In the entity form, column pickers now suggest supported @value references from the loaded project
    cache, and a preview button on a reference chip shows the exact columns it expands to, based on
    cached configuration, without changing your selection or saved YAML. Reference values you did not
    edit are saved back exactly as they were loaded.
- [PR #627](https://github.com/humlab-sead/sead_shape_shifter/pull/627) chore: promote dev into staging (merged 2026-10-29).
  - Promotes: #626.
- [PR #634](https://github.com/humlab-sead/sead_shape_shifter/pull/634) Reconciliation MVP: keyed decisions, owned links, and gated allocation (merged 2026-11-01).
  - User-facing release note:
    Reconciliation now requires explicit operator review: candidate search proposes matches keyed by
    business key, and only accepted decisions whose SEAD target is verified at export time become
    applied links. Rows marked local-only allocate a new ID only for entities using reconcile-exact or
    reconcile-fuzzy mode; all other unresolved rows are blocked rather than silently matched.
  - Upgrade notes:
    - Existing <project>-reconciliation.yml files at version 2.0 (or without a version) are ignored
    with a warning on load. Recreate reconciliation specifications and rerun candidate matching to
    populate the new version 3.0 catalog.
     - The mapping sidecar (<project>-mapping.yml) keeps its independent format; existing links continue
    to work, and owner, verified_at, and local_only_approvals are new optional fields written by the
    new export flow.
     - The automatic reconciliation_client injection into the SEAD change request ingester is removed;
    remove any explicit injection or reconciliation_query_columns / reconciliation_entity_types
    configuration from custom setups.
     - The RECONCILE planned-row action is renamed to BLOCK_RECONCILIATION (reconcile →
    block_reconciliation); update any code or tests referencing the old enum value.
     - Database-sequence ID reservation can now consume a sequence value during both validation and
    ingestion, so unused ID gaps are expected.
- [PR #633](https://github.com/humlab-sead/sead_shape_shifter/pull/633) Fix Pyright errors and add pandas\-stubs for type checking (merged 2026-11-01).
  - User-facing release note:
    User-visible impact not verified.
  - Upgrade notes:
    - Developers: re-sync the development environment (e.g. uv sync with the dev extra) to pick up the
    new pyright and pandas-stubs packages.
     - Deployers of the backend: project validation and ingestion now fail fast with a configuration
    error if INGEST_TARGET_HOST, INGEST_TARGET_DBNAME, or INGEST_TARGET_USER are unset, and ingesters
    registered for normalized-table input must implement the configured ingester lifecycle (Ingester
    plus table methods) or they are rejected with an explicit error.
