# What's New in v1.18.0

Date: 2026-01-31

## Changes

### [PR #197](https://github.com/humlab-sead/sead_shape_shifter/pull/197) Fix breadcrumb routing; add log viewer and editor improvements

Breadcrumb navigation now stays within the app instead of triggering full page loads. The Settings
page gains a Logs tab where users can view, filter by level, refresh (optionally every 30 seconds),
and download application and error logs, and double-clicking a node in the dependency graph with
Ctrl/Cmd opens the entity editor directly on its YAML tab.

### [PR #198](https://github.com/humlab-sead/sead_shape_shifter/pull/198) Fix breadcrumb routing, add log viewer and editor improvements \(\#196\)

Breadcrumb links now navigate within the app instantly instead of going through the server. The
Settings page gains a Logs tab where you can view, filter by level, auto-refresh and download
application and error logs, and Ctrl/Cmd+double-clicking an entity in the dependency graph opens its
editor directly on the YAML tab.

## Upgrade Notes

### [PR #197](https://github.com/humlab-sead/sead_shape_shifter/pull/197)

- Deployers: make update-deploy-scripts in docker/Makefile now invokes ./rsync-to-sead-tools in the
docker directory instead of deploy-to-sead-tools in the deploy source directory; ensure that script
is present. A new setup-permissions target applies setgid/setfacl permissions to the deploy
directory.
 - The backend adds a LOG_DIR setting that defaults to the existing LOGS_DIR value; no configuration
change is required.

### [PR #198](https://github.com/humlab-sead/sead_shape_shifter/pull/198)

No end-user action is required; the new logs endpoints read from LOG_DIR, which defaults to the
existing LOGS_DIR value (./logs). Deployers should note Makefile changes: update-deploy-scripts now
calls ./rsync-to-sead-tools and docker-restart now operates from the deploy directory, so those
scripts/paths must be present where the deployment tooling is used.
