# What's New in v2.8.0

Date: 2026-11-23

## Changes

### [PR #727](https://github.com/humlab-sead/sead_shape_shifter/pull/727) Expand target model to v2\.5\.0 with taxonomy, dating, and FK wiring

The SEAD standard target model now covers taxonomy hierarchy (order, family, genus, author), seasons, site preservation status, languages, data-type groups, record types, and property-type groups, with foreign keys wired to existing entities.

### [PR #729](https://github.com/humlab-sead/sead_shape_shifter/pull/729) Move completed FK proposals to done and fix column header layout

Column-type headers in the entity editor now display the column name and type selector side-by-side without the selector stretching to full width.

### [PR #730](https://github.com/humlab-sead/sead_shape_shifter/pull/730) Add output dataset expectations for full runs

Users can now define output dataset expectations for full runs, including checks on row counts and distinct keys, improving data validation and integrity.

### [PR #731](https://github.com/humlab-sead/sead_shape_shifter/pull/731) Add 23 target\-model entities and consolidate coverage docs

Projects can now declare 23 additional target-model entities covering site references, sample-group descriptions, lithology, dataset methods and submissions, analysis-entity ages and dimensions, measured values, species associations, taxa seasonality, taxonomy notes, and dating references. Projects that previously set `site.site_type_id` must supply `site_site_type` rows instead.

### [PR #733](https://github.com/humlab-sead/sead_shape_shifter/pull/733) feat\(workflow\): close resolved issues when a promotion reaches main

Issues resolved by a change are now closed automatically when the change is promoted into main.

### [PR #735](https://github.com/humlab-sead/sead_shape_shifter/pull/735) feat\(reconciliation\): rename sidecars to fixed names

Mapping and reconciliation sidecar files now use the fixed names shapeshifter.mapping.yml and shapeshifter.reconciliation.yml.

### [PR #736](https://github.com/humlab-sead/sead_shape_shifter/pull/736) fix\(materialization\): drop api\-only name from materialized source state

Materializing an entity no longer writes an environment-absolute file path or an API-only name key into materialized.source_state, so project YAML stays portable and unmaterialize restores the original relative file reference.

### [PR #737](https://github.com/humlab-sead/sead_shape_shifter/pull/737) fix\(frontend\): mount project tabs that load data on first activation

The Reconcile & Review tab now explains its workflow, grid columns, filters, and actions in context. Unmapped rows are labeled **New**, and the review grid is more compact and easier to scan.

### [PR #748](https://github.com/humlab-sead/sead_shape_shifter/pull/748) Reconciliation icons, business\-key validation, and blank current IDs

Reconciliation rows now use icons with hover tooltips for actions and states, making the grid easier to scan. A legend in the sidebar explains each action icon. Entities without business keys can no longer be used in reconciliation; a warning explains what to configure before saving or running.

### [PR #749](https://github.com/humlab-sead/sead_shape_shifter/pull/749) Improve reconciliation grid labels, column order, and ID display

Reconciliation grid filter chips now show their label and count together, the Status column appears first, and the confidence column is labeled "Score". The ID-source badge no longer appears when no IDs are present.

### [PR #750](https://github.com/humlab-sead/sead_shape_shifter/pull/750) Add source icons to ID badges and fix status priority

Current-ID badges now display a source icon and, for reconciliation links, a verification indicator. Rows with errors are labeled "Needs attention" instead of "Unreviewable," and hovering the status icon reveals the error details.

### [PR #752](https://github.com/humlab-sead/sead_shape_shifter/pull/752) Clarify reconciliation review labels and hide outdated preview

Reconciliation grid columns now use clearer labels such as "Review status", "Selected target ID", and "Score" instead of "Decision status", "Decision ID", and "Decision confidence". The Preview button is temporarily hidden while it is being updated.

### [PR #758](https://github.com/humlab-sead/sead_shape_shifter/pull/758) Add periodic git history snapshot of the deployment home directory

Operators can now record the deployment home directory in a local git repository on a schedule, enabling per-file recovery and change history alongside the existing archive backup.

### [PR #761](https://github.com/humlab-sead/sead_shape_shifter/pull/761) \#\# Summary

Users can now view property-mapped columns grouped together, improving grid readability. New actions for clearing decisions and deleting sidecar mappings provide more granular control over reconciliation entries.

### [PR #763](https://github.com/humlab-sead/sead_shape_shifter/pull/763) Make property mapping columns collapsible

Users can now collapse property mapping groups in the reconciliation grid, improving the interface and usability.

### [PR #764](https://github.com/humlab-sead/sead_shape_shifter/pull/764) \#\# Summary

Users can now promote changes from `dev` to `staging` without encountering provenance issues related to release commits that were pushed directly to `main`.

### [PR #769](https://github.com/humlab-sead/sead_shape_shifter/pull/769) Add Search and Browse for reconciliation records

Reviewers can search or browse target records in a persistent review pane and save several decisions together. Export verifies accepted target records before writing links.

## Upgrade Notes

### [PR #727](https://github.com/humlab-sead/sead_shape_shifter/pull/727)

The model version bumps from 2.1.0 to 2.5.0. Projects referencing the model gain 11 additional entities and new conditional foreign keys; existing project YAML is unaffected because all new FKs use `required_when.has_new_rows`. Test assertions pinning entity count (102 → 113) and conditional-FK count (1 → 2) must be updated if forked.

### [PR #731](https://github.com/humlab-sead/sead_shape_shifter/pull/731)

Projects that declare `site.site_type_id` directly (including arbodat-rebecka) must migrate to providing `site_site_type` bridge rows. The model no longer declares that column on `site`. No database migration is required; this is a model-configuration change only.

### [PR #735](https://github.com/humlab-sead/sead_shape_shifter/pull/735)

Rename each project's <project>-mapping.yml to shapeshifter.mapping.yml and <project>-reconciliation.yml to shapeshifter.reconciliation.yml before opening the project.
