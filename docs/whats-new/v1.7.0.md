# What's New in v1.7.0

Date: 2026-01-15

## Changes

### [PR #154](https://github.com/humlab-sead/sead_shape_shifter/pull/154) Add savable custom graph layout for the dependency graph

You can now arrange the dependency graph nodes the way you like and click "Save as Custom" to store
those positions with the project; the graph reopens in your saved layout on later sessions, and
"Clear Custom" removes it. Graph controls (fit, zoom, reset, PNG export) are now floating buttons
over a full-height graph area.

### [PR #158](https://github.com/humlab-sead/sead_shape_shifter/pull/158) Add context\-sensitive help, quick YAML editing and resizable sidebar

Help panels in the sidebar now explain what you can do on each screen, including graph interactions.
Clicking a node in the dependency graph opens a quick YAML editor so you can edit and save an
entity without leaving the graph, a new button lets you create an entity from the graph, and the
sidebar can be dragged to a comfortable width.

### [PR #159](https://github.com/humlab-sead/sead_shape_shifter/pull/159) Add custom graph layout, context\-sensitive help and graph tools

You can now arrange the dependency graph the way you think about your data and keep it that way:
drag nodes into place, click "Save as Custom", and the graph reopens in your saved layout next time
(shared with everyone via the project file). The sidebar also shows context-sensitive tips and
shortcuts for the view you are in, and the graph gains floating tools for zooming, resetting,
creating a node, and quick YAML editing from the node drawer.

## Upgrade Notes

### [PR #154](https://github.com/humlab-sead/sead_shape_shifter/pull/154)

- The default local backend port changed from 8012 to 8013 (Makefile and the Vite dev proxy
default). Update any local tooling or bookmarks that target the old port, or override BACKEND_PORT /
VITE_API_BASE_URL.
 - httpx is now a core (non-optional) dependency; reinstall dependencies (e.g. uv sync) after
pulling.
 - Saved layouts are written into the project file's options.layout.custom section, so project files
that use this feature will change on disk (backups are created on save).

### [PR #159](https://github.com/humlab-sead/sead_shape_shifter/pull/159)

- The default backend port changed from 8012 to 8013 (BACKEND_PORT in the Makefile and the Vite
dev-server proxy default). Update any local setup, scripts, or VITE_API_BASE_URL overrides that
assume port 8012.
 - httpx is now a core runtime dependency (previously only in the dev extra); reinstall dependencies
after pulling (e.g. uv sync).
 - Saved layouts are stored in the project YAML under options.layout.custom (see
input/arbodat-test.yml for an example). This section is optional and requires no migration of
existing projects.
