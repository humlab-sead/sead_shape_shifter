# What's New in v1.10.0

Date: 2026-01-18

## Changes

### [PR #172](https://github.com/humlab-sead/sead_shape_shifter/pull/172) Add Playwright E2E setup and fix project filename truncation

Projects whose names end in letters such as "l", "m" or "y" (or a dot) are now saved and reopened
under their full name instead of a truncated filename. The app also shows an updated SEAD logo,
favicon, and page title.

### [PR #173](https://github.com/humlab-sead/sead_shape_shifter/pull/173) Fix project name truncation; add Playwright E2E, Docker build script

Project names ending in letters such as "l", "m" or "y" are no longer truncated when saving or
loading, so projects created with those names can now be reopened correctly. The app also shows an
updated SEAD icon and browser tab title.

## Upgrade Notes

### [PR #172](https://github.com/humlab-sead/sead_shape_shifter/pull/172)

- Frontend developers must reinstall dependencies (pnpm install) to pick up the new
@playwright/test and svg2img dev dependencies, and install Playwright browsers before running the
new test:e2e* scripts (they expect the dev server on http://localhost:5173, which the Playwright 
config starts automatically).
 - Anyone referencing the sample file input/test_config_manua.yml must use the new name
input/test_config_manual.yml.

### [PR #173](https://github.com/humlab-sead/sead_shape_shifter/pull/173)

- Docker builds now route through docker/build.sh: make docker-build builds from GitHub main (with
cache busting); use make docker-build-local to build from the local working tree. Deployment
directories must receive the new build.sh (and BUILD_SCRIPT_GUIDE.md), which the updated
deploy-to-sead-tools script now copies.
 - The default container group GID in docker/Makefile changed from the sead user's group to the
www-data group; override USER_UID/USER_GID if your host differs.
 - To run the new E2E tests, install frontend dependencies (pnpm install) and Playwright browsers;
tests start the Vite dev server automatically via the Playwright webServer config.
