# What's New in v1.2.0

Date: 2026-01-12

## Changes

### [PR #135](https://github.com/humlab-sead/sead_shape_shifter/pull/135) Add ingester configuration support and enhance project detail loading

Project files can now define an ingesters section with a target data source and default options, and
the Data Ingestion form uses these settings automatically: the target database is shown from the
project's data source instead of being typed in manually, and options such as ignore columns are
pre-filled.

### [PR #136](https://github.com/humlab-sead/sead_shape_shifter/pull/136) Add ingester configuration support and enhance project detail loading

The data ingestion form now takes its target database and default settings (ignored columns,
register and explode options) from the project file's new ingesters section instead of requiring
manual database details, so ingestion runs with consistent, version-controlled defaults that can
still be overridden before submitting.

## Upgrade Notes

### [PR #135](https://github.com/humlab-sead/sead_shape_shifter/pull/135)

To use the new ingestion defaults, add an ingesters section to your project file's options and point
its data_source at an entry in options.data_sources (see docs/INGESTER_CONFIGURATION.md and
input/example-ingester-config.yml). The ingestion form no longer lets you enter database
host/port/name/user manually, so projects without an ingesters.<name>.data_source configuration will
see a warning that no target database is configured.

### [PR #136](https://github.com/humlab-sead/sead_shape_shifter/pull/136)

To use the new ingestion defaults, add an ingesters section under options in your project file and
point each ingester's data_source at an entry in options.data_sources (see
input/example-ingester-config.yml and docs/INGESTER_CONFIGURATION.md). Without it, the ingestion
form shows a warning that no target database is configured for the ingester, since the previous
manual database host/port/name/user fields and the output folder field were removed from the form.
