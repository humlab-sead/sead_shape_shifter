# What's New in v2.2.0

Date: 2026-09-23

## Highlights

- Add authentication and project-level permissions for shared deployments.
- Control access to shared data sources according to user roles and grants.
- Add a Podman deployment stack and scripts for installation, updates, and verification.
- Restrict project file access, query execution, and generated output paths.

## New Features

### User and project access

Administrators can configure users, roles, and project permissions. Access can be granted through groups, including wildcard-style project access. Project owners and maintainers can manage permitted project operations.

Access to shared data sources is checked separately from project access. Operators manage shared sources, while administrators control application logs and other administrative tasks.

### Deployment tools

Podman deployment files and scripts support installing, updating, and verifying Shape Shifter deployments. The setup includes authentication bootstrap and authorization administration tools.

## Improvements

- Data source status, query validation, and ingester operations now check the caller's permissions.
- Query execution applies input and result limits, and DuckDB external access is restricted.
- Deployment configuration and runtime files can be kept outside the application checkout.

## Upgrade Notes

For shared deployments, configure authentication and authorization before granting users access. Use the deployment guidance to set up the new roles and data source permissions.
