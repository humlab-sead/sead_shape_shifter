# What's New in v1.24.0

Date: 2026-03-17

## Changes

### [PR #351](https://github.com/humlab-sead/sead_shape_shifter/pull/351) Serve help docs from canonical docs directory and improve FK handling

The in-app Help page now always shows the latest documentation, the entity editor can auto-detect
columns from SQL queries, and the dependency graph gains edge-visibility toggles, adjustable label
sizes, and a dialog for planning new "todo" entities. Foreign key relationships now default to
rejecting null keys, and constraint failures show clearer, actionable validation messages.

## Upgrade Notes

### [PR #351](https://github.com/humlab-sead/sead_shape_shifter/pull/351)

- Breaking default change: allow_null_keys for foreign key constraints now defaults to false
(previously true) in the core, backend, and frontend schema. Existing projects whose FK joins rely
on null key values without explicitly setting allow_null_keys: true may now fail linking/validation;
review and set the flag explicitly where the relationship is intentionally optional.
 - Docker deployments: no operator action required, but the runtime image now uses a dedicated
/opt/venv virtual environment; custom images derived from the previous layout (site-packages copies)
need updating.
