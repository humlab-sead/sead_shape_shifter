# What's New in v1.6.0

Date: 2026-01-14

## Changes

### [PR #152](https://github.com/humlab-sead/sead_shape_shifter/pull/152) Add standalone Docker build target with minimal build context

The Docker image can now be built from GitHub in a standalone way (make docker-build-standalone)
from any directory, as long as the lib/ (UCanAccess) directory is present, without needing a full
repository checkout as build context.

## Upgrade Notes

### [PR #152](https://github.com/humlab-sead/sead_shape_shifter/pull/152)

- The lib/ directory (UCanAccess library) is no longer taken from the git clone and must be present
in the Docker build context. For standalone builds, lib/ must exist in the current directory; the
Makefile target fails with an error if it is missing.
 - docker-build-github and docker-build-tag must now be run from the project root directory, as they
build the context from ..
 - backend/__init__.py no longer creates the models, services, api, and tests directories (and their
__init__.py files) automatically on import; environments that relied on this side effect must
provide those directories themselves.
