# What's New in v1.27.0

Date: 2026-05-12

## Highlights

- New `type: internal` entity type — derive entities using SQL queries over already-processed entities.

## New Features

### DuckDB Internal SQL Loader (`type: internal`)

Entities can now be derived from one or more previously processed entities using a plain SQL query, without any external database connection.

```yaml
entities:
  site_summary:
    type: internal
    depends_on: [site, sample]
    query: |
      SELECT s.site_name, COUNT(sa.system_id) AS sample_count
      FROM site s
      JOIN sample sa ON sa.site_id = s.system_id
      GROUP BY s.site_name
    public_id: site_summary_id
    keys: [site_name]
    columns: [site_name, sample_count]
```

All entities processed before the DuckDB entity are available as SQL views by their entity name. The query runs against Shape Shifter's in-memory entity store — no `data_source` entry is needed.

**Requirements**:
- `query` — a valid SQL SELECT statement.
- `depends_on` — list of entity names referenced in the query. This controls processing order and ensures the referenced entities are available when the query runs.

See [CONFIGURATION_GUIDE.md](../CONFIGURATION_GUIDE.md#duckdb-internal-workspace) for details and examples.

## Upgrade Notes

No configuration changes are required for existing projects. The `duckdb` Python package is now a required dependency.
