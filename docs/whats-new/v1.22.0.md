# What's New in v1.22.0

Date: 2026-03-06

## Changes

### [PR #275](https://github.com/humlab-sead/sead_shape_shifter/pull/275) Add Files tab to upload project data files to project folders

Users can now open a project's new Files tab and drag-and-drop or browse to upload Excel and CSV
data files into the project folder, then use them in entity configurations with location: local.
Uploaded files are listed with their size and location.

### [PR #282](https://github.com/humlab-sead/sead_shape_shifter/pull/282) feat\(frontend\): add entity\-based append support in UI

Users can now choose "From Entity" in the Append Editor to append rows from another entity,
selecting the source entity and configuring column alignment (by position or explicit name mapping)
directly in the UI, instead of only Fixed Values or SQL Query appends.

## Upgrade Notes

### [PR #275](https://github.com/humlab-sead/sead_shape_shifter/pull/275)

The LOGS_DIR backend setting (previously an alias of LOG_DIR) has been removed; deployments that set
LOGS_DIR should use LOG_DIR instead. No database migrations are involved.
